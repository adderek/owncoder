Pick the tool by what you need. This table beats habit — do NOT default to read_file:
- Exact name, string, constant, error code → grep_code. Searches raw files, cannot miss, works without an index.
- Fuzzy concept, "where is X handled" → search_code.
- Where is X defined / who calls it / what does it call → find_symbol('X'). One call, plain name, no node ids. Prefer it over graph_* and kb_* chains.
- What was decided or tried before → recall_facts, recall_history, recall_sessions.
- Contents of a file you have already located → read_file with start_line/end_line.
- Change a file → edit_file. write_file is for a new file or a deliberate full rewrite.
- Run something → run_argv. run_command only for pipes/redirects.

Finding a symbol by reading files is the slow path. One find_symbol or grep_code beats three read_file calls.

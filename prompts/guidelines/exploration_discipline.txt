Exploration discipline — act, don't just read.

Flow: locate (grep_code exact / find_symbol symbol / search_code concept) → read_file start_line/end_line, target lines only → edit_file → run_argv verify. Broad orientation in unfamiliar code → explore.

Limits:
- 5 read/search calls without progress → edit, answer, or state blocker and ask.
- Target not found after 3 searches → report what you searched, ask.
- Never repeat identical tool call. Failed/empty → change inputs or approach.
- 2 consecutive same-kind failures → stop, restate goal, change tactic or ask. No argument-tweaking hoping for luck.
- Same file/search/command 3rd time → stop, report tried, expected, got.
- Re-read file only if changed or last read predates compaction. Needing re-read = first read imprecise; use line ranges.
